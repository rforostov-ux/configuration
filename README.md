# Эмулятор оболочки ОС

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Реализован этап 1 (REPL): минимальный прототип, в котором диалог
с пользователем уже работает, а большинство команд — заглушки.

## Требования

- Python 3.8 или новее (tkinter входит в стандартную установку)
- Внешние зависимости не нужны

## Запуск

```
python src/main.py [имя_VFS]
```

Или готовыми скриптами: `run.bat [имя_VFS]` (Windows),
`./run.sh [имя_VFS]` (Linux/macOS). Имя VFS показывается в заголовке
окна; если оно не указано, используется `vfs`.

## Возможности

| Команда | Что делает |
|---|---|
| `ls [аргументы]` | заглушка: печатает имя команды и аргументы |
| `cd [аргумент]` | заглушка: печатает имя команды и аргумент |
| `exit [код]` | закрывает окно, процесс завершается с указанным кодом |

### Парсер

- пробелы разделяют аргументы;
- `$VAR` и `${VAR}` раскрываются значением переменной окружения
  реальной ОС; неопределённая переменная даёт пустую строку;
- `"двойные кавычки"` сохраняют пробелы и раскрывают переменные;
- `'одинарные кавычки'` сохраняют текст как есть, без подстановок.

### Обработка ошибок

- неизвестная команда: `foo: команда не найдена`;
- незакрытая кавычка или `${`, неверное имя в `${}`:
  `синтаксическая ошибка: ...`;
- лишние аргументы у `cd` и `exit`;
- нечисловой аргумент у `exit`.

## Окно

Окно выглядит как терминал: сверху вывод, снизу строка ввода и справа
кнопка «Выполнить». Команду запускает Enter или кнопка. Ошибки
выделяются красным.

## Примеры

```
$ ls -l $HOME
ls: аргументы ['-l', '/home/user']
$ cd "$HOME/my dir"
cd: аргументы ['/home/user/my dir']
$ ls '$HOME'
ls: аргументы ['$HOME']
$ foo
foo: команда не найдена
$ ls "abc
синтаксическая ошибка: незакрытая двойная кавычка
$ exit abc
exit: abc: требуется числовой аргумент
$ exit 3
```

В Windows переменной `HOME` обычно нет, используйте `$USERPROFILE`
и `$USERNAME`.

## Тесты

Из корня репозитория:

```
python -m unittest discover -s tests -t .
```

## Структура проекта

```
src/
  main.py        точка входа
  gui.py         окно (tkinter)
  shell.py       выполнение команд
  cmd_parser.py  парсер строки и раскрытие переменных
tests/           модульные тесты (unittest)
run.sh, run.bat  скрипты запуска
```

Окно (`gui.py`) не знает про команды, а оболочка (`shell.py`) — про
окно: оболочка возвращает список сообщений, окно их показывает.

## Коммиты

Сообщения коммитов оформляются по спецификации Conventional Commits:
`тип(область): описание`, например `feat(repl): ...`, `fix(parser): ...`.
